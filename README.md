## ⚡ Key Highlights & Features

1. **Ultra-Modern Dark Theme & Design Tokens:**
   - Deep slate and carbon background (`#07090e`, `#0d121f`).
   - Dynamic vibrant accents: Electric Cyan (`#38bdf8`), Cyber Indigo (`#818cf8`), Neon Violet (`#c084fc`), and Mint Green (`#10b981`).
   - Built-in Dark / Light mode toggle switch.

2. **Full 3D Cursor-Tracking Tilt Physics:**
   - Cards dynamically compute exact mouse coordinates relative to their center (`rotateX` and `rotateY`).
   - Specular holographic light glare follows cursor movement on cards with spring-back physics on mouse leave.

3. **Dynamic Scroll-Reactive Navbar:**
   - Transparent at page top, automatically transforming into an ultra-premium frosted glass blurred navbar (`backdrop-filter: blur(14px)`) when scrolled down.

4. **Multi-Track Interactive Sliders:**
   - **Continuous Sliding Reviews Track:** Smooth auto-marquee of verified partner testimonials with pause-on-hover, mouse drag/swipe, and mouse-wheel support.
   - **Trusted Companies Marquee:** Fluid horizontal scrolling banner with mouse drag and hover-pause.

5. **Tailored Sections & Architecture:**
   - **Hero Section:** High-converting engineering copy with dual CTAs, live availability status beacon, and ambient glow.
   - **Capabilities (What We Specialize In):** 6 bespoke service cards with custom duotone gradient SVGs and technical feature lists.
   - **Process Roadmap (How We Build):** 4-step agile engineering delivery framework.
   - **Selected Case Studies (Portfolio):** Rich project cards with tech tags, metric badges, and explore links.
   - **Technology Ecosystem:** Categorized into 4 architecture clusters (Frontend, Backend, DevOps, AI/Models).
   - **Leadership Team:** Core executive profiles styled with custom avatar badges and "Coming Soon" member names.
   - **High-Impact CTA Section:** Direct Inquiry with response time indicator, LinkedIn, and Instagram channels.

## 🚀 Getting Started Locally

### 1. Prerequisites
- **Node.js:** v18.0.0 or higher (v20+ recommended)
- **npm:** v9.0.0 or higher (or pnpm / yarn)

### 2. Clone the Repository
```bash
git clone https://github.com/AbdulWasayAli/Aquila_Labs.git
cd "Aquila Labs Website"
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Run Development Server
```bash
npm run dev
```
Open your browser and navigate to the local address provided (typically `http://localhost:5173`).

## 📦 Production Build & Validation

To compile and optimize the website for production:

```bash
npm run build
```

This runs TypeScript check (`tsc`) and Vite production bundle optimization, outputting lightweight minified assets into the `dist/` directory.

To preview the production bundle locally:
```bash
npm run preview
```

## 🎨 Design System Variables (`src/style.css`)

The interface is driven by centralized CSS variables for rapid theme adjustments:
- `--bg-primary`: Deep background canvas (`#07090e`)
- `--surface-card`: Elevated surface color (`#0d121f`)
- `--surface-card-hover`: Hover state surface (`#131b2e`)
- `--accent-cyan`: Vibrant primary accent (`#38bdf8`)
- `--accent-blue`: Secondary cool accent (`#818cf8`)
- `--accent-gradient`: Linear gradient (`linear-gradient(135deg, #38bdf8, #818cf8)`)
- `--text-white`: Primary text (`#f8fafc`)
- `--text-body`: Secondary readable text (`#94a3b8`)
- `--border-subtle`: 1px border definition (`rgba(255, 255, 255, 0.08)`)
